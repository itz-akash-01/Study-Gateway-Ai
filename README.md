# Study_Gateway AI — HTML/CSS/JS prototype

Open `index.html` directly or use VS Code Live Server.

Includes the pastel liquid-glass UI, animated puppy welcome page, light/dark theme, Home, AI Studio, **History (replaces Books)**, Study Planner, Focus Timer, Profile, responsive mobile navigation and a Telegram link.

Important: This is a frontend prototype. Login does not authenticate users; Google login, account creation, password recovery, AI generation, file processing, database persistence and PPT export are not connected. Generated output is placeholder content. Before launch, connect a real auth provider (e.g. Firebase Auth), secure server-side AI endpoints, private storage and per-user authorization. Never put private API keys in frontend JavaScript. Treat ZIP uploads as untrusted and validate them on a backend.
